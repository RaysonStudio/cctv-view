# CCTV_View
(package name: com.raysonstudio.cctv_view)
(program Chinese name: 央视网)

## Short Introduction

An Android TV application for watching CCTV programs easily.

This app was developed with AI assistance.

## Full Information

- Android Version: Android 14 or higer
- Tested Device: Xiaomi TV S85 Mini LED
- Tested OS: Xiaomi HyperOS 3.0.103.0
- AI Assistance:
  - ChatGPT
  - Qwen3.7
- Package Name: com.raysonstudio.cctv_view

## How to Use

### For End Users

1. Download the latest version from [Releases](https://github.com/RaysonStudio/cctv-view/releases).
2. Copy the `.apk` file to your USB flash drive.
3. Insert the USB flash drive into the TV.
4. Open the `.apk` file and install the app.
5. Open the app list and launch "央视网".

## For Advanced Users

This project contains the Android TV client application.
You can clone this project and modify the server IP to connect to your own server.

The server project provides configuration data for the app.
You can clone the [server project](https://github.com/RaysonStudio/cctv_view_server/) and modify the default channel or other server-side settings.
